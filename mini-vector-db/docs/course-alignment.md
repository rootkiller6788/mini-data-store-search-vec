## 学习目标

完成本模块后，学生应能:

1. **理解**: 解释 ANN 搜索与精确搜索的区别和权衡
2. **实现**: 用 C 语言实现 HNSW, IVF-PQ, LSH 索引
3. **分析**: 比较不同 ANN 算法的时间/空间复杂度
4. **评估**: 用 Recall@k 和 QPS 评估索引性能
5. **应用**: 将向量搜索集成到 RAG, 推荐系统等场景
6. **优化**: 根据数据和查询特征选择合适的索引参数

## 实验建议

1. **Lab 1: KNN 基础** — 实现暴力搜索，理解距离度量
2. **Lab 2: LSH 实验** — 调整哈希表数和哈希函数数，观察召回率变化
3. **Lab 3: HNSW 实现** — 比较不同 M, efConstruction 对性能的影响
4. **Lab 4: IVF-PQ 实验** — 观察 nlist, nprobe, M 参数对速度和内存的影响
5. **Lab 5: 综合对比** — 在相同数据集上对比四种算法的 Recall-QPS 曲线
